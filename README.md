# MDGhashange 🌟 | نمایشگر و ویرایشگر فوق‌العاده زیبای مارک‌داون

یک اپلیکیشن دسکتاپ مدرن، سبک و با امکانات کامل برای ویندوز که با هدف **نمایش و ویرایش بسیار شکیل و بی‌نقص فایل‌های Markdown (.md)** به همراه پشتیبانی اختصاصی از زبان فارسی و راست‌چین (RTL/LTR Bidi) توسعه یافته است.

---

## 🌟 امکانات جدید و اختصاصی (Features):

1. **یکپارچگی با کلیک‌راست ویندوز (Open With & File Associations):**
   - اتصال خودکار به پسوندهای `.md`، `.markdown`، `.mdown` و `.txt`.
   - با راست‌کلیک روی هر فایل مارک‌داون و انتخاب **Open with > MDGhashange** فایل مستقیماً در برنامه‌ باز می‌شود.
   - پشتیبانی از اجرای چندباره: اگر برنامه باز باشد، فایل جدید در یک تب جدید باز می‌شود.

2. **خروجی سه‌گانه حرفه‌ای (فقط و فقط از متن زیبای رندر شده):**
   - 📄 **خروجی PDF برداری:** ایجاد مستقیم فایل PDF استاندارد با کیفیت چاپ بالا، پشتیبانی کامل از جدول‌ها، دیاگرام‌ها و فرمول‌های ریاضی KaTeX.
   - 🌐 **خروجی HTML مستقل (Standalone HTML):** تولید فایل HTML کامل همراه با فونت‌های تعبیه شده Vazirmatn و استایل‌های زیبا که در هر مرورگری بدون نیاز به اینترنت اجرا می‌شود.
   - 📘 **خروجی Microsoft Word (DOCX):** تبدیل مستقیم محتوای شکیل رندر شده به فایل واقعی و استاندارد `.docx` با حفظ تیترها، جداول و متون.
   - 📖 **[مشاهده راهنمای کامل خروجی گرفتن](راهنمای_خروجی_گرفتن.md)**

3. **بستن تب‌ها با کلیک وسط موس (Middle Click to Close):**
   - دقیقاً همانند مرورگرهای مدرن (گوگل کروم)، با فشردن چرخ یا کلیک وسط موس روی هر سربرگ (Tab)، آن تب فوراً بسته می‌شود.

4. **سیستم پیشرفته کپی (Copy Options):**
   - **کپی متن زیبا (Copy Formatted):** متن رندر شده را با تمام قالب‌بندی‌ها، رنگ‌ها، لیست‌ها و جداول در کلیپ‌بورد کپی می‌کند تا با یک `Ctrl+V` تمیز در Word، تلگرام، ایمیل یا نرم‌افزارهای آفیس درج شود.
   - **کپی کد HTML رندر شده:** کپی کدهای HTML پیش‌نمایش.
   - **کپی مارک‌داون خام:** کپی متن اصلی Markdown.
   - **منوی راست‌کلیک نیتیو:** راست‌کلیک در تمام بخش‌های برنامه دارای منوی استاندارد Cut، Copy، Paste و Select All است.
